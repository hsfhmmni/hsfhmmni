## 🎬 Maths animation with Manim

I make 3Blue1Brown-style explainer videos with [Manim](https://www.manim.community/), the Python animation library.

### [Daily Integral, animated](https://github.com/hsfhmmni/daily-integral-manim)

Every day's Medium and Hard integrals from [dailyintegral.com](https://dailyintegral.com), solved and animated: picture first, a question, rectangles that converge, the key idea highlighted, equations that morph. **52 videos so far**, each checked automatically against the website's own TeX for LaTeX, layout and numerical accuracy, and approved by hand before it is published.
